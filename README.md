# Cronograma do Lar

Cronograma de educação domiciliar do 1º ao 4º ano, baseado em *Educação no Lar*, de Charlotte Mason.
App instalável (PWA) para Android, iPhone e computador: plano diário e semanal, leitura dos livros da família, diário de aulas com fotos e uso sem internet.

Os registros, fotos e o progresso ficam salvos no próprio aparelho.
